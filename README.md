## Projects

### 1. Copilot Studio Dataverse Integration
**Location:** `/copilot-studio-dataverse-integration`

A complete end-to-end solution for integrating Microsoft Copilot Studio with Dataverse to retrieve and display HR links using Adaptive Cards.

**Features:**
- Natural language query processing
- Dataverse table integration
- Power Automate flow examples
- Adaptive Card templates
- JSON response formatting
- Support for 100+ records

**Quick Start:**
```bash
cd copilot-studio-dataverse-integration
node demo/demo-query.js
```
