# 🚀 Getting Started in 1 Minute

## What is This?

A complete solution to let users ask questions like **"Get my reward statement"** and instantly receive a clickable link in a beautiful card format.

## What You'll Build

```
User types:     "Get my reward statement"
                      ↓
System shows:   ┌─────────────────────────────────┐
                │ 🔗 Reward Statement             │
                │ Access your reward information  │
                │ [View Reward Statement] ← Click│
                └─────────────────────────────────┘
                      ↓
Browser opens:  https://hr.company.com/rewards
```

## What You Need

- ✅ Microsoft 365 account
- ✅ 30 minutes of time
- ✅ Basic knowledge of clicking buttons 😊
